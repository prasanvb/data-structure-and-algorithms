| Bubble Sort | Compare adjacent items (compare 0 to 1, 1 to 2, and so on) and bubble the bigger value to the end and repeat the process. Moves the bigger value to the End. |
| --- | --- |
| Selection Sort | Select an item (start in index 0) and compare it with each item in the array and repeat the process. Moves the smaller value to the Beginning. |
| Insertion Sort | Compare adjacent items (compare 1 to 0 ,  2 to 1, and so on) and insert the smaller item to the beginning by doing backwards comparison until it reach right spot. (compare n to n-1) |
| Quick Sort | Recursive Divide and Conquer approach |
